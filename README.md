# 🎓 EduLens

> An AI-powered educational platform designed to make learning smarter, more interactive, and personalized.

## 🚀 Overview

**EduLens** is an AI-driven education platform that helps students learn more effectively by combining modern web technologies with artificial intelligence.

The platform is designed to provide students with intelligent assistance, interactive learning experiences, and useful educational tools through a clean and intuitive interface.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/AmritpaL-Singh0945/EduLens.git
cd EduLens
```

### 2. Install dependencies

If the project has separate frontend and backend directories:

```bash
cd frontend
npm install

cd ../backend
npm install
```

### 3. Configure environment variables

Create a `.env` file in the required directory and add your API credentials:

```env
AI_API_KEY=your_api_key_here
```

> Never commit your `.env` file or expose API keys publicly.

### 4. Start the application

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```

## 🧠 How It Works

EduLens follows a simple AI-powered workflow:

```text
User
  ↓
React Frontend
  ↓
Backend API
  ↓
AI Service
  ↓
AI-Generated Response
  ↓
Educational Interface
```

The frontend handles user interaction, the backend manages application logic and API communication, and the AI layer generates intelligent educational responses.
